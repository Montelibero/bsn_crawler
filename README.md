# bsn_crawler

Штукенция, что лазает по блокчейну Stellar и собирает BSN данные в один JSON файл, 
а другие сервисы используют эти данные.

## Что именно делает

Собирает аккаунты, открывшие линию доверия к токенам MTLAP, MTLAC, EURMTL. Для каждого считывает DATA.
В этих данных ищет:

1. Подписи под документами (такие пары, где значение похоже на SHA-256 хеш)
2. Ссылочные теги (имя похоже на тег, а значение на стеллар аккаунт)
3. Теги самопрезентации (имя похоже на тег, а значение — любое другое)

Также записываются балансы для некоторых токенов МТЛ-токеномики.

Имена DATA нормализуются одинаково для ссылочных тегов и профиля: уточнение после первого `:`
игнорируется, а завершающие цифры удаляются как технический индекс для повторяющихся DATA ENTRY.
Ссылки аккаунта на самого себя сохраняются.

В итоге этой работы порождается `bsn.json` файл, который для начала лежит в именованном docker хранилище,
но в итоге публикуется по адресу https://bsn.expert/json.

## Надёжность публикации

- Значения Stellar ManageData, попадающие в профиль, должны быть корректным UTF-8 без управляющих байтов
  (перевод строки и табуляция разрешены). Остальные значения пропускаются с записью в лог. JSON
  сериализуется в строгом режиме; ошибка кодировки отменяет публикацию.
- Все JSON, gzip и HTML артефакты сначала записываются в новый каталог поколения и проверяются чтением,
  JSON-декодированием, распаковкой gzip, размером и SHA-256. После этого ссылка `current` переключается
  одним атомарным `rename`. Имена `bsn.json`, `bsn.json.gz`, `bsn-extra.json,gz` и `bsn.html.gz`
  остаются совместимыми ссылками на текущее поколение.
- Одновременно может работать только один сборщик. При ошибке последнее корректное поколение сохраняется.
- Запросы к Horizon имеют таймаут подключения 10 секунд и общий таймаут 30 секунд. Запрос registry
  известных токенов имеет общий таймаут 15 секунд.
- Docker healthcheck проверяет целостность и согласованность артефактов, а также требует, чтобы `createDate`
  был не старше 15 минут.

## Как запустить

`docker compose up`

Локальные проверки: `cd crawler && composer install && composer test`.
